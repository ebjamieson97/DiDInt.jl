Staggered Adoption

This example illustrates a staggered adoption setting in which ten states adopted merit-aid programmes at different points between 1991 and 2000.

Running didint()

# Note that treated_states & state column in the merit data could alternatively
# be string vectors, here they just happen to be numeric codes instead of state names
treated_states = [34, 57, 58, 59, 61, 64, 71, 72, 85, 88];
treated_times  = [2000, 1998, 1993, 1997, 1999, 1996, 1991, 1998, 1997, 2000];

result = didint(
    "coll", "state", "year", merit;
    treatment_times = treated_times,
    treated_states  = treated_states,
    seed       = 1234,

    covariates = [:male, :asian, :black],

Running didint_plot()

didint_plot() can produce data for two types of plots depending on the event argument.

By default, the outputted dataset will include the parallel trends (or event study) data for each ccc option ("hom", "time", "state", "add", "int") as well as the data estimated without covariates ("none"). You can specify which ccc options you want to plot by inputting a vector of strings to the ccc argument.

Parallel trends plot data

Setting event = false returns a long-format DataFrame of residualised outcome means by state and period, suitable for plotting parallel trends across CCC specifications.

These plots remain valid for assessing parallel trends under every ccc option except "int". Under "none", "hom", "state", "time" and "add", how the series of a treated state changes over time relative to the series of its controls is exactly the comparison that didint() bases its estimates on. The level of a plotted series does rest on a convention: a covariate-adjusted mean has to be evaluated at some values of the covariates, and the plotted values are evaluated at covariates equal to zero. Under these options, however, a different choice of covariate values would make the plotted series shift together. Under "hom" and "time", every state's series would move by the same amount in a given period; under "state", each state's series would move up or down by an amount that is the same in every period; under "add", both happen at once. In every case, whether the series move in parallel is unaffected.

Under ccc = "int" with covariates this is no longer true, and the plots should be interpreted with care. The covariate coefficients are then specific to each state and period, so a different choice of covariate values would change each plotted point by its own amount, and series that look parallel at covariates equal to zero need not look parallel at other covariate values. The plot therefore depends on how the covariates are coded (measuring age in years, or in years above 40, gives different plots). The "int" estimates of didint() do not rest on the plotted values either: they evaluate the changes over time at the covariate means of each treated state (see the Integrated Long Differences section). The "int" series describe the outcome at covariates equal to zero, and parallel or non-parallel series there are not, on their own, evidence for or against the parallel trends that the "int" estimates rely on.

plot_parallel = didint_plot(
    "coll", "state", "year", merit;
    treatment_times = treated_times,
    treated_states  = treated_states,
    event      = false,
    covariates = ["asian", "black", "male"]
);

Separate ATTs by Policy

When treated states adopt different policies, the policy aggregation options report an ATT for each policy. The merit data does not record different types of merit-aid programmes, so purely for illustration the ten treated states are split here into two made-up policy types, "A" and "B", using the treated_policies argument (the pvar argument can be used instead when the policy is stored in a column of the data).

treated_policies = ["A", "A", "B", "A", "B", "A", "B", "B", "A", "B"];

Cohort ATTs With and Without Policies

agg = "cohort" reports one ATT per treatment time and ignores the policies, whereas agg = "policy_cohort" reports one ATT per treatment time within each policy. With the made-up policies above, the two treated states of the 1998 cohort have different policies, as do the two treated states of the 2000 cohort; the two states of the 1997 cohort both have policy "A", and every other cohort consists of a single state.

Comparing the two sets of results:

  • The 1998 and 2000 cohorts, which contain both policies, are each split in two: one ATT for the state with policy "A" and one for the state with policy "B". Each of these is now based on a single treated state, so it has no jackknife standard error. The split can matter: the 2000 cohort has an ATT of about -0.025 as a whole, which is made up of about -0.046 under policy "A" and 0.070 under policy "B".
  • The cohorts that contain a single policy (1991, 1993, 1996, 1997 and 1999) appear once, under that policy, with the same ATT and standard errors as under agg = "cohort". Their randomization inference p-values differ slightly, because for the policy aggregation options a state's policy is reassigned together with its treatment time.
  • The weight column now gives the weight of each cohort ATT within its policy, and the ATT of each policy (the first table of the output) is the weighted mean of the cohort ATTs of that policy. There is no single aggregate ATT; setting policy_aggregation = true adds the pooled ATT across policies, as in the example above.

The Aggregate ATT Across Aggregation Options

With the default weighting (weighting = "both"), and also with weighting = "att", the aggregate ATT does not depend on the agg option (see the Aggregate ATT Equivalency section). Running the staggered adoption example above with every (non-policy) agg option and the default weighting:

aggs = ["cohort", "simple", "state", "sgt", "time", "calendar"]

results = [didint(

    seed       = 1234,
    ccc        = "state",
    covariates = [:male, :asian, :black],

Common Adoption

A Single Control State

This example compares a single treated state (state 71, treated in 1991) against a single untreated control state (state 73). With agg = "sgt", an ATT is reported for state 71 in each period from 1991 onwards. With only one control state, the usual standard error of each of these ATTs cannot be computed; setting edgecase = true recovers it from the first-stage estimates instead.

merit_pair = filter(row -> row.state ∈ [71, 73], merit);

result_pair = didint(
    "coll", "state", "year", merit_pair;
    treated_states  = [71],
    treatment_times = [1991],
    seed       = 1234,
    ccc        = "hom",
    covariates = [:male, :asian, :black],
    agg        = "sgt",
